### Penjelasan Sistem Kerja Cloud Real-Time Baru: 1. **Penyimpanan Instan di Cloud (Firestore):** Kami menerapkan konfigurasi database cloud Firestore menggunakan path `/artifacts/{appId}/public/data/` yang aman dan terisolasi. 2. **Koreksi & Rekap Otomatis:** Saat siswa mengklik **"Kirim Jawaban Akhir"**, seluruh jawaban PG dan esai mereka langsung diterbangkan ke server. Anda sebagai Guru dapat melihat dan memeriksa hasilnya secara real-time di tab **"Rekap Nilai Siswa"** dengan menekan tombol **"Periksa Detail"** untuk melihat secara persis apa saja jawaban esai siswa Anda tanpa perlu proses salin manual via WA lagi. 3. **Gratis & Tanpa Instalasi Tambahan:** Anda tidak perlu setup server hosting, semuanya berjalan lancar di browser, hanya dengan satu file HTML mandiri ini.
